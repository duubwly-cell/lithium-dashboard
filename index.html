📰 产业链资讯
以下是今日碳酸锂/锂电产业链相关资讯整理：

1. **价格与市场**
市场竞争加剧，起亚EV4宣布大幅降价1万美元。特斯拉在加州的销量暴跌24%，该州电动车市场创2021年以来新低。特斯拉第一季度财务表现受到质疑，这些都反映出当前电动车市场面临的下行压力和价格战。

2. **供给动态**
特斯拉的锂精炼厂废水被检测出有毒金属，面临停产要求，给锂供应带来环保挑战。宁德时代计划在2026年推出续航超370英里的钠离子电池，为锂电池提供了潜在替代方案。同时，宁德时代还推出了可在6分钟内充满电的LFP电池，显著提升了现有锂电池的性能和充电效率。

3. **需求动态**
需求端出现显著分化，通用汽车和Jeep暂停了下一代电动卡车和唯一的电动车型在美国的上市计划，显示部分车企对EV策略的调整。尽管有宝马i7、丰田/雷克萨斯电动SUV以及大众捷达电动SUV等新车型推出，但特斯拉在加州销量大幅下滑。中国太阳能和美国风能的强劲增长，以及超快充技术的进步，预示着电池在储能和电动车基础设施方面的长期需求潜力。

4. **政策与地缘**
本轮资讯中暂无直接的政策或地缘政治相关动态。特斯拉锂精炼厂面临的环保问题，属于监管层面的挑战。

**综合判断：**
近期电动车市场需求疲软的信号明显，加之车企价格战和部分车型的暂停，预示着短期内碳酸锂价格将面临较大的下行压力。

⚡ 边际变化追踪
津巴布韦锂矿 中性
津巴布韦于2026年4月将锂精矿出口禁令调整为配额制，要求矿商2027年前建成锂盐加工厂。华友Arcadia锂硫酸盐工厂预计2026年Q1投产。未找到赣锋Bikita矿的近期进展。
📌 津巴布韦政府于2026年4月取消了全面的锂精矿出口禁令，改为有条件地发放出口配额，但强制要求本地加工。
📊 短期内锂精矿供应紧张可能缓解，但长期政策趋向本地化加工，若加工能力未及时跟上，仍可能对碳酸锂价格产生支撑。
宁德宜春枧下窝矿 利空
宁德时代宜春枧下窝锂矿在采矿证于2025年8月到期后停产，并已完成首次环评公示和矿种变更为“锂矿”的关键节点。然而，截至2026年4月，该矿尚未恢复生产，摩根士丹利预计复产时间将推迟至2026年第四季度。
📌 截至2026年4月，宁德时代宜春枧下窝锂矿尚未恢复生产，摩根士丹利预计复产将推迟至2026年第四季度。
📊 枧下窝锂矿的持续停产以及宜春地区其他锂矿的合规整顿将导致锂供应阶段性收紧，对碳酸锂价格形成上行支撑。
智利锂国有化 中性
智利SQM与Codelco合资企业于2026年1月正式成立，标志着智利锂国有化战略核心落地，Atacama盐湖运营权延长至2060年。
📌 智利SQM与国有企业Codelco的合资企业NovaAndino Litio于2026年1月正式成立，并获得最高法院及监管机构批准，将统一运营Atacama盐湖锂资源至2060年。
📊 该合资企业强化了智利对锂资源的国家控制，通过更集中的供应管理，长期来看可能对全球碳酸锂供应的稳定性及价格形成支撑。
阿根廷锂三角 利多
阿根廷米莱政府推出Rigi大型投资激励制度和矿业改革法案，大幅降低税率并提供30年政策稳定承诺，吸引了包括力拓和赣锋锂业在内140亿美元的锂矿投资。预计到2030年，阿根廷将新增8个锂矿项目，产能翻倍，成为全球锂供应增长的重要驱动力。
📌 阿根廷政府正式颁布Rigi大型投资激励制度及相关法令，并通过矿业改革法案，为锂矿开发提供长期稳定的优惠政策和法律保障。
📊 阿根廷锂矿产能的持续释放预计将主导2027-2030年全球锂供应增量，可能缓解全球锂资源短缺并对未来碳酸锂价格形成一定压制，但短期内市场关注度提升或带来积极情绪。
澳矿产量/停复产 利多
Core Lithium获得融资并决定重启Finniss锂矿，预计2026年5月开始采矿。Liontown的Kathleen Valley矿已全面转为地下开采，产量显著增长。Pilbara Minerals计划在2026年7月重启Ngungaju工厂。澳大利亚锂产量预计在2026年反弹。
📌 Core Lithium和Pilbara Minerals均宣布重启此前停产的锂矿项目，且Liontown的Kathleen Valley项目产量持续增长。
📊 锂矿供应增加，或对短期碳酸锂价格带来一定压力，但反映出市场对长期需求前景的信心。
国内政策动向 中性
中国新能源汽车购置税减半、电池出口退税率下调，同时强化锂资源管理，并出台新型储能制造业高质量发展方案，引导产业高质量发展。
📌 电池产品出口退税率自2026年4月1日起下调，并计划于2027年完全取消。
📊 短期内政策调整可能抑制部分需求，但锂资源管理加强和储能需求增长将为碳酸锂价格提供长期支撑。
