**供给动态**
Stellantis计划利用其在加拿大的闲置工厂生产中国零跑电动车，这反映了全球汽车制造领域的国际合作与产能布局的调整。小松（Komatsu）推出全球最大的电动挖掘机，预示着重型机械电动化趋势下对电池需求的新增长点。目前资讯更多聚焦于下游制造的产能调配和新应用，而非直接的锂原料供给变动。

**需求动态**
全球电动汽车需求持续强劲，比亚迪海外订单激增至“新水平”。美国密歇根州投入5100万美元完善电动汽车充电网络，XCharge和JOJO也在伊利诺伊州启动快速充电站，显著改善了基础设施。此外，石油危机促使消费者考虑电动车，家庭太阳能、储能与电动车一体化方案也日益普及。电动两轮车和电动重型机械的推广也共同推动了整体需求增长。

**政策与地缘**
中东地缘紧张局势导致的油价上涨，间接刺激了消费者对电动汽车和家庭太阳能解决方案的需求。美国密歇根州政府投入巨资完善电动汽车充电网络，并有计划免费更换故障充电桩，体现了政府对电动汽车基础设施建设的积极政策支持。Stellantis与中国零跑汽车的国际合作，也可能涉及跨国贸易和产业政策的考量。

**综合判断**
当前电动汽车及相关储能领域的市场需求旺盛，且整车价格竞争激烈，基础设施建设加速。尽管缺乏直接的锂原料供需数据，但下游需求的强劲增长和成本控制压力，将对碳酸锂价格形成一定支撑，但近期大幅上涨的可能性受限于产业链的效率提升和市场竞争格局。

⚡ 边际变化追踪
津巴巴韦锂矿 中性
津巴布韦于2026年2月25日立即实施了锂原矿及锂精矿出口禁令，旨在推动本地加工。华友Arcadia矿的硫酸锂工厂预计在2026年第一季度投产，而赣锋Bikita矿正在与政府协商恢复出口并计划建设硫酸锂工厂。
📌 津巴布韦政府于2026年2月25日宣布立即并无限期暂停所有锂原矿和锂精矿出口，较原计划提前。
📊 出口禁令预计将扰乱全球锂辉石供应链，导致短期内供应紧张，可能推高碳酸锂价格。
宁德宜春枧下窝矿 中性
宁德时代宜春枧下窝锂矿已于2025年底获得采矿证，但复产流程仍在审批中。受中央督察影响，宜春锂矿供应短期收缩，复产仍存不确定性。
📌 宁德时代表示，宜春枧下窝锂矿已于2025年底获得采矿证，但复产流程仍在政府审批中，公司将在新周期中加快推进。
📊 短期内供应受限将对碳酸锂价格形成支撑，但长期看该矿复产将增加供应预期。
智利锂国有化 中性
智利国家矿业公司Codelco与SQM之间在阿塔卡马盐滩的锂合资企业NovaAndino Litio已于2026年4月初正式完成。智利最高法院驳回了SQM股东天齐锂业的上诉，为该协议的执行扫清了障碍。此举是智利国家锂战略的基石，旨在确保该地区锂生产持续到2060年，并计划大幅提高产量。
📌 智利最高法院驳回天齐锂业上诉，Codelco与SQM的锂合资企业于2026年4月6日正式完成。
📊 该合作预计将长期增加智利的锂产量（到2030年产能将增至30万吨/年），这可能缓解全球供应担忧，从而对碳酸锂价格构成长期下行压力。
阿根廷锂三角 利多
米莱政府推行亲商政策，通过RIGI和十年锂矿路线图吸引外资，并与美国签署关键矿产协议。同时，阿根廷参与“锂欧佩克”协议以提升定价权。汇率改革也正进行。
📌 南美“锂三角”三国（智利、玻利维亚、阿根廷）签署“联合资源储备协议”（即“锂欧佩克”），旨在控制锂矿出口和价格。
📊 “锂欧佩克”协议旨在推高碳酸锂价格，同时阿根廷的亲商政策及外资进入可能稳定长期供应。
澳矿产量/停复产 利多
Core Lithium Finniss项目获全额注资，预计2026年Q4复产。Pilbara Minerals Ngungaju工厂计划2026年7月复产。Liontown Kathleen Valley加速扩产并完成地下矿转型。市场普遍预期2026年锂供应将从过剩转向短缺。
📌 Core Lithium的Finniss锂矿项目已获得最终投资决定和全额资金，计划于2026年第四季度重启生产。
📊 随着主要矿山复产和增产，短期可能增加市场供应，但鉴于2026年全球锂市场预期将出现供应短缺，长期而言将对碳酸锂价格形成支撑。
国内政策动向 利多
中国在2026年3-4月持续实施新能源汽车购置税减半和以旧换新补贴政策，以刺激需求。工信部强调关键材料自主保障，国务院出台锂矿项目限制政策，推动锂资源规范开发与盐湖提锂技术突破。固态电池产业化进程正在加快，这些政策整体利好锂电及碳酸锂市场长期发展。
📌 中国继续实施新能源汽车购置税减半和以旧换新补贴政策，并加强锂资源管理，限制无序扩张；同时加速固态电池技术产业化。
📊 预计将持续刺激新能源汽车市场需求，同时规范锂资源开发，共同支撑碳酸锂市场在紧平衡格局下长期稳定向好。
