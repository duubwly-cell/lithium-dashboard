⚡ 边际变化追踪
津巴巴布韦锂矿 中性
津巴布韦政府于2026年4月上旬“软解除”2月生效的锂精矿出口禁令，改为配额出口制，要求矿企承诺2027年前建设硫酸锂加工厂。华友Arcadia锂矿的硫酸锂工厂预计2026年初投产，多家中国矿企已获出口配额。
📌 津巴布韦政府于2026年4月上旬“软解除”锂精矿出口禁令，实行有条件的配额出口制，要求矿企承诺本地深加工。
📊 短期内部分锂精矿供应将恢复，缓解市场紧张情绪。长期则推动本地深加工，可能增加矿企成本，对碳酸锂价格影响中性偏多头。
宁德宜春枧下窝矿 利空
宁德时代宜春枧下窝锂矿自2025年8月停产至今尚未复产。摩根士丹利预计其复产将推迟至2026年第四季度。同时，宜春其他锂矿也面临停产换证影响国内锂云母供应。
📌 摩根士丹利在2026年4月发布的报告中，将宁德时代宜春枧下窝锂矿的复产时间推迟至2026年第四季度。
📊 枧下窝矿及宜春其他锂矿的持续停产换证，加剧国内锂矿供应紧张，叠加海外因素，预计将支撑碳酸锂价格高位运行。
智利锂国有化 利多
智利锂资源国有化进程取得重大进展，SQM与Codelco的锂业务合并已于2026年1月完成，成立合资公司NovaAndino Litio，并于2026年4月23日智利最高法院驳回上诉后获最终确认。Codelco将持有多数股权，确保阿塔卡马盐滩的锂生产至2060年。
📌 2026年1月，智利最高法院驳回天齐锂业上诉，SQM与Codelco的锂业务合并正式完成，并于2026年4月23日再次确认。
📊 该合作协议的最终执行提升了智利锂资源的长期供给确定性，理论上可能对碳酸锂价格产生一定的长期利空影响，但短期市场已对此消息有所反应。
阿根廷锂三角 利多
阿根廷米莱政府通过矿业改革法案吸引外资，计划2030年前新增8个锂矿项目，大幅提升产能。 虽面临通胀和厄尔尼诺短期挑战，但外资企业积极布局，多盐湖项目和直接提锂技术加速发展。
📌 阿根廷众议院通过矿业改革法案，放宽冰川保护限制，旨在吸引更多锂矿外资。
📊 长期来看，阿根廷锂矿产量的大幅增长潜力将对全球碳酸锂价格构成下行压力，但短期内厄尔尼诺气候风险可能带来波动。
澳矿产量/停复产 利多
澳大利亚锂矿行业近期动态积极。Pilbara Minerals在2026年3月季度实现了创纪录的锂精矿产量，Ngungaju工厂计划于2026年7月重启。Core Lithium的Finniss项目获得全面资金并获批重启，预计2026年5月开始采矿，并计划在2026年第四季度发运首批锂精矿。然而，澳大利亚正面临柴油短缺的潜在风险，可能影响锂矿生产。
📌 Core Lithium的Finniss锂矿项目获得全额资金并获批重启，计划于2026年5月恢复露天采矿作业。
📊 尽管部分矿山产量指引下调及柴油短缺构成潜在风险，但主要矿企的增产和项目重启以及市场对2026年供需趋紧的预期，预计将对碳酸锂价格形成正面支撑。
国内政策动向 利多
中国近期政策聚焦新能源汽车及锂电产业高质量发展与可持续性。国家实施汽车“以旧换新”补贴，调整新能源车补贴侧重技术，并于4月24日落地废旧动力电池回收利用管理办法。同时，工信部等四部门就电池产能过剩召开座谈，并自4月1日起下调电池出口退税率，旨在引导产业从规模扩张转向技术创新。锂电储能市场转向市场驱动，碳酸锂价格呈上涨趋势。
📌 2026年4月24日，工信部等六部委联合发布的《新能源汽车废旧动力电池回收和综合利用管理暂行办法》正式全国落地实施，旨在加强回收管理和促进动力电池维修信息透明化。
📊 政策引导行业高质量发展和资源循环利用，加之储能需求强劲及全球锂资源供需趋紧，预计将对碳酸锂价格形成支撑，并推动其维持在较高区间波动。
